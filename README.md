# RK Design — بورتفوليو رمضان قطب

موقع بورتفوليو ثابت (HTML/CSS/JS بدون أي أدوات بناء) — يفتح مباشرة بفتح `index.html` في المتصفح، أو برفعه على أي استضافة عادية.

## هيكل الملفات
```
/index.html                الصفحة الرئيسية
/graphic-design.html       قسم تصميم الجرافيك
/interior-design.html      قسم التصميم الداخلي
/3d-visualization.html     قسم تصور الثري دي
/project.html              قالب صفحة المشروع الواحد (يعمل بمعامل ?id=)
/about.html                من أنا
/contact.html              تواصل معي
/css/style.css             كل تنسيقات الموقع
/js/projects.js            ← بيانات كل المشاريع (المكان الوحيد للتعديل غالبًا)
/js/main.js                السلوكيات: القوائم، الفلاتر، اللايت بوكس، السكرول
/images/projects/          صور المشاريع
/images/brand/             صورة غلاف الهيرو وأي صور هوية
```

## إزاي تضيف مشروع جديد (الطريقة السهلة — من غير كود)
افتح ملف `admin.html` في المتصفح (مش لينك ظاهر للعملاء، للاستخدام الشخصي بس):
1. حط صور المشروع داخل مجلد `images/projects/` بأسماء إنجليزي بسيطة
2. املأ الفورم في `admin.html` واختار نفس الصور
3. دوس "توليد الكود" ثم "نسخ الكود"
4. افتح `js/projects.js` والصق الكود مباشرة بعد سطر `const PROJECTS = [` ثم احفظ

المشروع هيظهر أوتوماتيك في صفحة القسم المناسب وفي صفحة تفاصيله الخاصة — من غير ما تلمس أي HTML.

## إزاي تضيف مشروع جديد (الطريقة اليدوية — لو مرتاح للكود)
1. افتح `js/projects.js`
2. انسخ أي عنصر (object) من مصفوفة `PROJECTS` وعدّل بياناته:
   - `discipline`: لازم تكون واحدة من `"graphic"` أو `"interior"` أو `"3d"`
   - `cover`: مسار صورة الغلاف داخل `images/projects/`
   - `gallery`: مصفوفة صور إضافية (اختياري)
   - لو لسه مفيش صورة جاهزة، اسيب `cover: null` وهيظهر تلقائيًا إطار بديل أنيق بعنوان المشروع لحد ما تضيف الصورة الحقيقية
3. احفظ الملف

## إزاي تغيّر بيانات التواصل
غيّر رقم الهاتف والروابط (Behance / Instagram / LinkedIn) في تذييل كل صفحة (`<footer>`) وفي `contact.html`. لو حابب توحّدهم من مكان واحد مستقبلًا ينفع تتحول لملف `js/site-config.js`.

## ملاحظات
- الموقع RTL بالكامل ومبني بخط Cairo للعناوين وTajawal للنصوص (Google Fonts).
- فورم التواصل حاليًا واجهة فقط بدون إرسال فعلي (لازم تربطه بخدمة زي Formspree أو باك إند بسيط لاستقبال الرسائل فعليًا).
- **قسم تصميم داخلي وقسم تصميم جرافيك دلوقتي فيهم صورك ومشاريعك الحقيقية** (تم ترتيبها وتقسيمها تلقائيًا من الفولدرات اللي بعتها).
- **قسم تصور ثري دي لسه Placeholder** — مبعتش فولدر صور له، فلو عندك رندرات ثري دي منفصلة ابعتها أو ضيفها بنفس طريقة `admin.html`.
- حجم مجلد الصور حاليًا كبير نسبيًا (لأن الصور بجودة عالية زي ما رفعتها). لو حسّيت إن الموقع بيفتح ببطء، قولي وهضغطها من غير ما تقل الجودة بشكل ملحوظ.
